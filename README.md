My personal NixOS desktop — flake-based, **Hyprland on Wayland**, with a **custom Quickshell QML bar** built from scratch instead of Waybar.

API documentation for the Quickshell bar (auto-generated by Doxygen on every push to master): **[rabbbba.github.io/nixos-config](https://rabbbba.github.io/nixos-config/)**.

Where this is going: [`ROADMAP.md`](ROADMAP.md) and the [project board](https://github.com/users/Rabbbba/projects/2).

## Highlights — what to look at if you have 5 minutes

The most interesting code lives in **`quickshell/`** — a hand-rolled QML status bar:

| Path | What it is |
|---|---|
| `shell.qml` | Top-level `ShellRoot`, layout of the three module groups |
| `services/Visibilities.qml` | Singleton coordinating which popout is open at any time (one at a time) |
| `services/Players.qml` | MPRIS player resolver, kept reactive to player hot-plug via `Connections` |
| `services/CpuUsage.qml`, `GpuUsage.qml` | `/proc` + sysfs polling for CPU/GPU load and VRAM; temperatures sourced from the native `NativeHwmon` C++ plugin |
| `plugin/native_network.cpp` | Native C++ QML type reading `/proc/net/route` + `/sys/class/net` for throughput, replacing a per-tick `sh -c` fork |
| `components/PopoutItem.qml` | Positioned popup host with click-outside-to-close via `HyprlandFocusGrab` |
| `components/Tooltip.qml` | Hover tooltip with 300 ms delay and fade-in |
| `modules/bar/Tidal.qml` | Now-playing pill + popout with album art and a live [cava](https://github.com/karlstav/cava) 24-band equalizer that doubles as a seek bar |
| `services/Theme.qml` + `services/ColorTokens.qml` | Theme tokens singleton with semantic sub-namespaces (`Theme.color.accent`, `Theme.font.sizeMd`, `Theme.anim.fast`). Color tokens live in `ColorTokens.qml`, regenerated by matugen from the current wallpaper. |

What the bar does:
- Hyprland workspace pills with active / occupied / urgent / hover states (animated width)
- Center clock with click-to-open calendar popout
- Tidal MPRIS popup with album art, transport, volume slider, live cava equalizer
- Wi-Fi / Ethernet auto-detection via Quickshell.Networking, signal strength on the Wi-Fi glyph
- Pipewire volume control with mouse-wheel scroll
- Hover tooltips with dynamic content (e.g. `Wi-Fi: <SSID> (<signal>%)`)
- Power menu in a popout opened by the Nix-logo button on the left

## Layout

```
flake.nix                  # inputs: nixpkgs, home-manager, quickshell
configuration.nix          # NixOS system: boot, network, GPU, services
home.nix                   # user packages, dotfile symlinks, sessionVariables
hardware-configuration.nix # generated by nixos-generate-config (machine-specific)
quickshell/                # ⭐ the custom QML bar
  ├── shell.qml
  ├── components/          # PopoutItem, Tooltip, IconButton, StyledText, Sparkline, ProgressBar, ExclusionZone, KeyValueRow, SectionHeader
  ├── modules/bar/         # Clock, Cpu, Gpu, Ram, Audio, Bluetooth, Network, SystemTray, Tags, Title, Tidal
  ├── popouts/             # Audio, Bluetooth, Calendar, Cpu, Gpu, Ram, SystemTray, Tidal, Wifi, Power
  ├── services/            # Visibilities, Players, Cpu/Gpu/Ram/NetworkSpeed Usage, Tick, Theme, ColorTokens
  └── plugin/              # native C++ NativeSensors module (NativeHwmon, NativeRam, NativeNetwork)
hypr/                      # Hyprland WM config
nvim/                      # Neovim (NvChad)
foot/                      # terminal
```

## Hardware

This config is shaped around my desktop:

- **CPU/GPU**: AMD (configured for gaming via Steam, Proton, gamescope, MangoHud)
- **Monitors**: Dell 3440×1440 (DP-2, primary, where the bar lives) + AOC 1920×1080 portrait (DP-1)
- **Games disk**: mounted at `/mnt/jeux`

To run on different hardware, regenerate `hardware-configuration.nix` and adjust monitor descriptors in `hypr/modules/monitors.conf` (matched on EDID `desc:`) and the screen filter in `quickshell/shell.qml`.

## Replicate

```bash
# 1. Clone
sudo git clone https://github.com/Rabbbba/nixos-config /etc/nixos

# 2. Regenerate hardware specifics
sudo nixos-generate-config --show-hardware-config | sudo tee /etc/nixos/hardware-configuration.nix

# 3. Edit home.nix for your username, homeDirectory, and git identity

# 4. Build (nh is the nix-helper wrapper; `nixos-rebuild switch` also works)
nh os switch

# 5. (Optional) The pre-commit hooks (statix, deadnix, nixfmt, shellcheck,
#    stylua, and Doxygen-on-staged-QML) are defined in the flake via
#    pre-commit-hooks.nix and install themselves the first time you enter
#    the dev shell (next step).

# 6. (Optional) Drop into the dev shell to get all the linting / docs
#    tooling on PATH (doxygen, statix, deadnix, qmllint, shellcheck...).
nix develop
# or with direnv: `echo "use flake" > .envrc && direnv allow`
```

## Maintenance

```bash
# Update flake inputs and rebuild in one shot
nh os switch --update

# Test a build without making it the default boot entry
nh os test

# Garbage collect old generations
nh clean all

# Rollback to previous generation
sudo nixos-rebuild switch --rollback
```

## System choices

A few system-level decisions worth calling out, each driven by a concrete problem on this hardware:

- **Encrypted DNS via a local `dnscrypt-proxy`** (`configuration.nix`) — DoH to Mullvad's adblock resolver, with `resolv.conf` pinned to `127.0.0.1` and NetworkManager kept out of DNS (`dns=none`). `systemd-resolved` is deliberately off: NM hands the ISP's DHCP DNS to it over D-Bus regardless of `dns=none`, leaking plaintext queries per link — a local forwarder sidesteps that.
- **`greetd` + `tuigreet` instead of a graphical display manager** (`configuration.nix`) — GDM's `gdm-wayland-session` exits immediately on RDNA4 + Mesa 26.1, and SDDM-on-Wayland fails differently. A TUI greeter in the TTY launches Hyprland through `uwsm` with no intermediate compositor.
- **CachyOS BORE kernel** (`flake.nix` overlay) — a latency-tuned scheduler; prebuilt binaries from `nix-cachyos-kernel` avoid a ~40 min compile.
- **AMD `amdgpu.overdrive` enabled** (`configuration.nix`) — disables `PP_GFXOFF` via `ppfeaturemask`. That idle power-saving feature adds a ~10 ms wake-up per token on local LLM inference; turning it off takes a Qwen run from ~9 to ~25 tokens/s.

## Notable patterns

A few design choices worth pointing out — first the system/Nix side, then the Quickshell bar:

- **Hot-reloadable dotfiles via `mkOutOfStoreSymlink`** (`home.nix`) — instead of letting home-manager copy configs into the read-only Nix store, every dotfile is symlinked back to `/etc/nixos/<dir>` with `config.lib.file.mkOutOfStoreSymlink`. Result: editing `hypr/`, `quickshell/`, `nvim/`, etc. takes effect immediately (lazy.nvim picks up the new plugin, `hyprctl reload` re-reads the conf, Quickshell live-reloads QML) without a `nh os switch`. Rebuild is only needed when adding *new* configs or system-level options.
- **Monitor matching by EDID `desc:`** (`hypr/modules/monitors.conf`) — Hyprland's `DP-1` / `DP-2` names are assigned by DRM probe order and shuffle across boots, breaking workspace pinning. Matching on the EDID descriptor (`monitor = desc:Dell Inc. AW3423DWF 5LKG2S3, ...`) is stable across reboots, kernel updates, and cable swaps.
- **Devshell + pre-commit lint chain** (`flake.nix` via [pre-commit-hooks.nix](https://github.com/cachix/pre-commit-hooks.nix)) — `nix develop` exposes `doxygen`, `nixfmt`, `statix`, `deadnix`, `stylua`, `qmllint`, `shellcheck` on PATH and installs a pre-commit hook that runs `statix`, `deadnix`, `nixfmt`, `shellcheck`, `stylua`, and Doxygen-on-staged-QML — only on the file types actually staged, so a commit touching only `.lua` doesn't pay the Doxygen cost. Same checks are mirrored in CI.
- **State-lifting via a `Visibilities` singleton** (`services/Visibilities.qml`) — instead of every popout owning its own `visible` flag, one singleton holds a `current` string. Click handlers call `Visibilities.toggle("calendar")`, popouts bind `visible: Visibilities.current === "calendar"`. Result: only one popout open at a time, central place to wire `Escape` or click-outside, and trivial coordination with future panels (launcher, OSD, lock).
- **MPRIS reactivity via `Connections`** (`services/Players.qml`) — `Mpris.players.values.find(...)` only resolves once when bound; if Tidal launches after Quickshell, the player stays `null`. Fix is an explicit `Connections { target: Mpris.players; function onValuesChanged() { ... } }` that re-runs the lookup on every change.
- **Wallpaper-driven theme** (`services/Theme.qml` + `services/ColorTokens.qml` + `matugen/`) — Color tokens are regenerated by [matugen](https://github.com/InioX/matugen) into `ColorTokens.qml` from the current wallpaper using the Material You 3 palette. `Theme.qml` is a static aggregator that exposes three sub-namespaces (`Theme.color`, `Theme.font`, `Theme.anim`) so consumers have a single point of access and matugen only rewrites the generated half. Tokens use semantic names (`windowBg`, `accent`, …) rather than positional ones, so renaming or repurposing a role doesn't require touching every consumer.
- **Click-outside-to-close popouts via `HyprlandFocusGrab`** (`components/PopoutItem.qml`, `shell.qml`) — popout contents live in a fullscreen `panelPopout` window, each wrapped in a `PopoutItem` positioned under its triggering bar module. A single `HyprlandFocusGrab` over that window closes the active popout when focus leaves it, so dismissal is centralized instead of re-implemented per popup. Hover tooltips are a separate, lighter primitive (`components/Tooltip.qml`): a fixed text bubble with a hover-delay timer.
- **Native C++ QML plugin for sysfs polling** (`plugin/`, `flake.nix`) — instead of spawning a shell (`sh -c … cat …`) every tick like a typical QML bar, sensor reads live in a compiled `NativeSensors` module: `NativeHwmon` (hwmon temperatures, parametrized by sensor/index/root), `NativeRam` (`/proc/meminfo`), and `NativeNetwork` (`/proc/net/route` + interface throughput). Each type owns a `QTimer`, reads sysfs with `std::ifstream`, dedups, and exposes type-safe `Q_PROPERTY` values that QML binds reactively. A Nix derivation builds the `.so` onto `QML_IMPORT_PATH`, and the bar runs as a systemd user service so that path is present at boot. Removes the per-tick `fork`/`exec` and the dependency on shell utilities.
- **Composable `ModuleWrapper`** (`modules/bar/ModuleWrapper.qml`) — every bar module wraps its content in this shell, which provides uniform hover background animation, click + scroll signals, and the tooltip plumbing. Adding a new module means writing the content and picking a tooltip string.
